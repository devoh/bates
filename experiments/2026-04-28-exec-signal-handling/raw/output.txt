NOTES
-----
- An earlier run (without `Process.flag(:trap_exit, true)`) crashed the
  script when the linked erlexec child exited with status 15 in the
  WITH-exec case. The script process received `(EXIT from ...) {:exit_status, 15}`
  from the linked erlexec process and propagated. After adding trap_exit
  the script observes the exit message instead of dying. Behavior of the
  child processes themselves was identical in both runs; only the host
  script needed to handle the linked exit.
